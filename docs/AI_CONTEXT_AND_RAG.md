# 上下文连续生成、Prompt 模板与素材库说明

本项目已补充更接近大模型应用开发的生成链路，不再只是“点一个按钮调用一次 AI”。

## 新增能力

1. 上下文连续生成
   - 生成章节时自动读取小说基础信息、人物设定、世界观设定、章节大纲、历史章节摘要和素材库。
   - 后端统一通过 `build_generation_context()` 组装上下文，再交给 AI 服务。

2. Prompt 模板管理
   - 新增 `prompt_templates` 表和 `/api/prompt-templates` 接口。
   - 内置创意生成、人物设定、世界观、大纲、章节正文、续写、润色、改写、摘要记忆等模板。
   - 前端高级功能里提供“Prompt 模板”页面，可编辑和新增模板。

3. AI 生成质量评分和重试
   - 章节生成后会检查必要字段、正文长度和格式。
   - 如果缺字段、正文过短或格式异常，会自动带着质量反馈重试一次。
   - 生成历史记录会保存质量分、质量报告和重试次数。

4. 章节摘要 / 记忆机制
   - 章节保存或更新时自动生成 `summary` 和 `memory_keywords`。
   - 后续章节生成会注入最近历史章节摘要，减少剧情断裂和设定矛盾。

5. RAG 素材库 / 设定库
   - 新增 `knowledge_items` 表和素材 CRUD 接口。
   - 支持保存角色卡、世界规则、伏笔、平台规则、参考资料。
   - 生成章节时按小说、大纲、关键词和用户指令做轻量检索，并把相关素材注入 Prompt。

## 简历可写法

- 设计多任务 Prompt 模板体系，覆盖创意生成、人物设定、世界观、大纲、正文生成、续写、润色、改写和章节摘要等 9 类任务，支持按题材和创作阶段动态组装提示词。
- 实现长篇小说上下文连续生成链路，自动注入小说设定、人物卡、世界观、章节大纲、历史章节摘要和素材库检索结果，提升长篇内容一致性。
- 增加 AI 生成结果质量评分与自动重试机制，对字段缺失、正文过短、格式异常等问题进行治理，并记录质量分、报告和重试次数。
- 构建章节摘要与记忆机制，章节保存后自动提取剧情摘要和关键词，供后续章节生成复用。
- 实现轻量 RAG 素材库模块，支持作者维护设定库、角色卡、伏笔和参考资料，并在生成时进行相关内容检索注入。
